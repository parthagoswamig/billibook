KhataPe Documentation

GST/VAT Invoicing, Billing & Inventory Management System

Version 1.0.0

1. System Requirements

  • Node.js: v16.x or higher
  • Package Manager: npm or yarn
  • Database: Supabase (Free or Self-hosted PostgreSQL)
  • Hosting: Vercel, Netlify, cPanel, or any static Node web server

2. Database Setup (Supabase)

  1. Create a free account on Supabase.com.
  2. Create a new project and wait for database setup to finish.
  3. Go to SQL Editor in your Supabase Dashboard.
  4. Open the schema.sql file provided in this package, copy its full content, paste it into SQL Editor, and click RUN.
  5. Go to Project Settings → API to find your Project URL and anon / public key.

3. Application Installation

  1. Unzip the package and open the project directory in your terminal.
  2. Create a file named .env by duplicating .env.example.
  3. Fill in your Supabase credentials in .env: 
    REACT_APP_SUPABASE_URL=https://your-project.supabase.co
REACT_APP_SUPABASE_ANON_KEY=your-supabase-anon-key
  4. Install dependencies: 
    npm install
  5. Start local development server: 
    npm start

4. Production Deployment (Vercel / Netlify)

  1. Push your codebase to your GitHub / GitLab repository.
  2. Connect your repository to Vercel or Netlify.
  3. Add the Environment Variables (REACT_APP_SUPABASE_URL and REACT_APP_SUPABASE_ANON_KEY) in your deployment dashboard settings.
  4. Click Deploy. Your application will be live in 1 minute!

5. Features Overview

  • ⚡ Compliant GST/VAT Invoicing: Auto-calculate CGST, SGST, IGST, or Custom Sales Tax.
  • 📦 Inventory & Stock Management: Real-time stock auto-adjustments upon sale or purchase.
  • 🔍 Barcode & QR Scanner POS: Camera and USB barcode scanner support.
  • 👥 Team & Role Permissions: Delegate bookkeeping to Accountants or Viewers.
  • 📶 Offline Billing Support: Queue invoices offline and auto-sync when connection restores.
